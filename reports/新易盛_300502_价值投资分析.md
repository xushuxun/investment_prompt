## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

新易盛是全球光模块第一梯队供应商，核心收入来源为**高速率光模块（800G/1.6T）**，深度绑定北美五大云厂商（英伟达、谷歌、Meta、亚马逊、微软）。海外收入占比超94%。

- **收入驱动**：AI算力爆发→数据中心光互联需求激增→800G/1.6T光模块量价齐升
- **盈利驱动**：高端产品占比高（4.25G以上产品收入占比>98%）→毛利率维持47%以上
- **生产模式**：研发+制造一体化，泰国/中国双基地布局

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 中 | 稳定 |
| 转换成本 | ✅ | 中高 | 增强 |
| 网络效应 | ❌ | — | — |
| 规模经济 | ✅ | 中高 | 增强 |
| 牌照壁垒 | ❌ | — | — |

**护城河评级**：**窄→中等** — 光模块行业技术迭代极快（每1-2年一代），客户认证周期长达12-18个月，先发者有一定时间窗口优势。但**没有结构性壁垒**：技术路线可被追赶，客户可切换供应商， capex 门槛并非不可逾越。中际旭创、Coherent 等持续扩产，竞争在加剧。

## 六、内在价值估算

### 资产法（下行保护）

```
净现金/可交易证券：  ≈¥38亿（2025Q1货币资金估算）
+ 应收账款 × 70%：   ≈¥25亿（2025Q1应收约36亿，打7折）
+ 固定资产（保守）：  ≈¥20亿
- 总负债：            ≈¥78亿（2025年末）
= 清算价值：          ≈¥5亿（每股：≈¥0.5）
```

⚠️ 清算价值极低，因为负债中绝大部分是经营性应付账款/票据，真实净现金头寸有限。

### 盈利法（持续经营）

采用**两种情景**：

**情景A：保守（正常化利润）**
```
正常化净利润（近5年均值）：  (6.87+9.05+6.88+28.38+95.32)/5 = ¥29.3亿
× 合理PE（10x，高科技制造业）：                    10x
= 盈利价值：                                       ¥293亿（每股：¥29.4）
```

**情景B：乐观（假设2025年利润可持续）**
```
正常化净利润（2025年）：    ¥95.32亿
× 合理PE（15x，给予一定成长性溢价）：              15x
= 盈利价值：                                       ¥1,430亿（每股：¥143.8）
```

**情景C：李录式极端保守**
```
正常化净利润（假设2026年后回落至¥50亿/年）：        ¥50亿
× 合理PE（8x）：                                   8x
= 盈利价值：                                       ¥400亿（每股：¥40.2）
```

### 综合内在价值：¥40–¥145/股

取中值约 **¥90/股** 作为参考。

**安全边际 = (90 - 718) / 90 = -698%**

当前股价 **¥718** 比最乐观的内在价值估算（¥145）仍高出 **395%**。

## 七、能力圈判定

- **10年后最坏情况**：AI算力投资退潮→光模块需求断崖式下跌→价格战爆发→毛利率跌至20%以下→净利润回落至10-20亿/年，PE压缩至15-20倍→市值300-400亿（当前1/20）。信心度：**中**
- **最强的反对理由**：「AI是百年一遇的技术革命，光模块是算力时代的「卖铲人」，需求只会越来越大，66倍PE对一家净利润两年翻3倍的公司并不贵。」
- **我的回应**：
  1. 就算AI需求持续增长，**光模块不是「卖铲人」而是「耗材配件」**，技术迭代导致每一代产品生命周期仅2-3年，没有持续的定价权；
  2. 历史证明，所有「这次不一样」的高估值最终都回归均值；
  3. 2026Q1环比下滑已是第一个裂缝；
  4. 即使按最乐观的2027年净利润277亿（方正证券预测），当前7154亿市值对应PE仍达26倍，对于制造业并不便宜。
- **能力圈结论**：**明确在内** — 光模块生意模式可以理解，但结论非常清晰：当前价格没有任何安全边际，不在「可以买」的范围内。

### 买入策略
- **理想买入价**：内在价值 × 50% = ¥90 × 0.5 = **¥45**
- **可接受买入价**：内在价值 × 70% = ¥90 × 0.7 = **¥63**

- **建议仓位上限**：D级 → **0%**

### 卖出触发条件
- 若已持有：股价 > 内在价值 × 1.5 → 卖出
- 基本面：护城河消失（技术被颠覆）/ 管理层诚信问题升级 / ROIC连续下滑至<15% → 清仓
- 当前信号：实控人持续减持、环比首次下滑、机构资金净流出——这些都是「应该卖出」而非「买入」的信号

### 一句话投资论文

> 以**负698%**的安全边际「买入」一家**周期性的光模块代工企业**，市场因**AI狂热**将其推至66倍PE、35倍PB的极端估值，管理层**持续减持且诚信存疑**，10年后最坏情况是**需求退潮+价格战导致市值缩水80-90%**，这是**不可接受**的。

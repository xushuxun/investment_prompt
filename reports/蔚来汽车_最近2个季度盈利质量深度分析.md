### 2.2 GAAP vs Non-GAAP：差距有多大？

```
2026Q1利润调节表（亿元）

GAAP净亏损：                    -3.32亿
加回：股权激励(SBC)             +3.76亿  ← 最大的调整项
─────────────────────────────────────────
Non-GAAP净利润：                +0.44亿

换句话说：
• 如果不加回股权激励，蔚来Q1亏损3.32亿
• 加回股权激励后，"盈利"0.44亿
• 0.44亿 ÷ 255亿营收 = 利润率0.17%
```

**关键问题**：股权激励不是"假成本"——它是真实的人才成本，只是以股票而非现金支付。Non-GAAP将其剔除，制造了"盈利"的假象。

## 三、盈利来源拆解：是"赚出来"的还是"省出来"的？

### 3.1 毛利端：确实有改善

| 驱动因素 | 2026Q1表现 | 是否可持续 |
|:---------|:----------:|:----------:|
| **高毛利车型占比提升** | ES8占比>50%，均价39万 | ⚠️ 依赖单一车型 |
| **整车毛利率18.8%** | 同比+8.6pct，连续四季度提升 | ✅ 趋势向好 |
| **其他销售毛利率20.6%** | 换电/售后首次高盈利 | ✅ 商业模式验证 |
| **自研芯片降本** | 神玑芯片替代Orin，省1万/车 | ✅ 持续释放 |
| **规模效应** | 季度交付8.3万辆 | ✅ 持续增长 |

**毛利端的结论是积极的**：毛利率确实在真实改善，不是靠会计手法。

### 3.2 费用端：主要是"省出来"的

```
2026Q1费用削减对"利润"的贡献测算

研发费用削减：
  2025Q1: 31.81亿
  2026Q1: 18.85亿
  节省: 12.96亿  ← 直接增加利润

销管费用削减：
  2025Q1: ~44亿
  2026Q1: 34.97亿
  节省: ~9亿  ← 直接增加利润

合计费用节省: ~22亿

2026Q1 Non-GAAP经营利润: 0.668亿
如果没有费用削减，经营利润 = 0.668 - 22 = -21.3亿

结论：利润 largely 是"砍费用"砍出来的
```

| 费用项 | 2025Q1 | 2026Q1 | 同比变化 | 原因 |
|:-------|:------:|:------:|:--------:|:-----|
| 研发费用 | 31.81亿 | 18.85亿 | **-40.7%** | "组织优化"=裁员 |

| 合计 | ~76亿 | 53.82亿 | **-29.2%** | — |

**关键问题**：
- 研发费用从31.8亿砍到18.9亿——这是"可持续的效率提升"还是"透支未来的裁员"？
- 李斌说"用20亿做到别人35亿的效果"——但如果竞争对手投入35亿，蔚来20亿够用吗？
- 销管费用削减20.5%——是否会影响销售能力和品牌建设？

## 四、会计手法检视：蔚来用了哪些"技巧"？

### 4.1 技巧一：Non-GAAP口径（最大"技巧"）

```
为什么公司喜欢报Non-GAAP？

GAAP（美国通用会计准则）：
  → 要求计入股权激励成本
  → 要求计入资产减值损失
  → 要求计入重组费用
  → 净利润 = -3.32亿

Non-GAAP（公司自定义口径）：
  → 剔除股权激励（+3.76亿）
  → 剔除其他"一次性"费用
  → "净利润" = +0.44亿

问题的本质：
  股权激励不是"假成本"——它是用股票支付给员工的真金白银
  如果不用股票支付，就要用现金支付，现金流压力更大
  所以Non-GAAP利润是"会计幻象"，不是真实盈利能力
```

**对比其他车企**：
- 理想汽车：GAAP和Non-GAAP差距很小（因为股权激励占比低）
- 特斯拉：早期也 heavily 依赖Non-GAAP，但成熟后差距缩小
- 蔚来：Non-GAAP比GAAP多了4-7亿每季度——差距巨大

### 4.2 技巧二：研发费用全部费用化（反向操作）

这是蔚来**没有使用**的会计手法，反而值得肯定：

```
李斌的声明（2025年7月直播）：

"这些亏损都是实实在在的研发投入，全部费用化，
 没有经过任何资产化处理，采用最严格的会计准则。
 
 如果自己真的把其中的一两百亿研发费用资本化处理掉，
 那财报绝对会好看的多，但是自己并没有这么做。"
```

**这是什么意思？**

| 会计处理 | 费用化 | 资本化 |
|:---------|:-------|:-------|
| 当期利润影响 | 直接减少利润 | 不减少利润（摊销到未来）|
| 资产表影响 | 无 | 增加无形资产 |
| 典型公司 | 蔚来、特斯拉早期 | 很多中国车企 |
| 对投资者 | 更保守、更可信 | 当期利润更好看 |

**结论**：蔚来在研发费用上确实采用了最保守的会计政策，这是加分项。如果蔚来像某些车企那样将研发费用资本化，历史累计亏损会减少几十亿甚至上百亿。

### 4.3 技巧三：收入确认时点

**检视**：蔚来是否有提前确认收入的行为？

```
蔚来收入确认政策：
• 整车销售：交付时一次性确认
• BaaS电池租赁：按月确认（递延收入）
• 换电服务：服务完成时确认
• 智能驾驶订阅：按订阅期分摊

未发现明显问题：
• 应收账款增速与营收增速基本匹配
• 没有大规模"渠道压货"的迹象
• BaaS递延收入合理
```

**结论**：收入确认没有发现明显的会计操纵。

### 4.4 技巧四：存货计价与减值

```
2024年末存货：169亿（同比+53%）
2025H1存货：169亿

关注点：
• 存货大幅增加是否为了"囤货"美化短期数据？
• 蔚来表示：为保证交付，主动加大备货
• 没有大规模计提存货减值

风险：
• 如果老车型（5/6/7系）销量下滑20%，库存可能需要减值
• 2025年存货周转天数52天，在增加
```

### 4.5 技巧五：资产减值损失

```
关键问题：蔚来是否少提了资产减值？

潜在减值风险：
• 换电站资产：~100亿+，技术路线（超快充）可能冲击换电价值
• NIO House租赁资产：~50亿+，直营模式持续亏损
• 无形资产（研发资本化）：蔚来声称全部费用化，所以风险较低
• 商誉：蔚来收购活动较少，商誉风险低

2024-2025年资产减值：
• 未发现大规模计提
• 但这可能是因为"全部费用化"政策下，可减值资产本身就不多
```

## 六、环比分析：盈利的可持续性

### 6.1 2025Q4 → 2026Q1 的剧烈变化

```
Non-GAAP净利润环比变化:

2025Q4: 7.2亿  ████████████████████████████████████████
2026Q1: 0.44亿 ███
        暴跌94%

原因拆解：
• 营收环比下降26%（春节淡季）
• 但费用也下降了
• 为何利润暴跌94%？

核心原因：
1. 高毛利车型（ES8）在Q4集中交付，Q1占比下降
2. Q4有年末促销费用集中确认，Q1费用"前低后高"
3. 原材料涨价成本在Q1开始显现（库存缓冲结束）
4. 单车成本增加超1万元
```

### 6.2 管理层对盈利可持续性的态度

| 指标 | 管理层指引 | 解读 |
|:-----|:----------|:-----|
| 全年整车毛利率 | 17%-18% | 低于Q1的18.8%，承认压力 |
| 研发费用 | 每季度20-25亿 | 比Q1的18.9亿要高——费用将回升 |
| 销管费用率 | 占销售收入10% | Q1实际13.7%，仍有差距 |
| 全年盈利目标 | Non-GAAP全年盈利 | 不是GAAP盈利——留了退路 |

**关键信号**：管理层自己都对Q1的盈利水平不自信——
- 全年毛利率指引下调
- 研发费用要回升到20-25亿
- 全年目标是Non-GAAP而非GAAP盈利

## 九、投资者应该看什么？

### 9.1 不要被"盈利"叙事误导

| 不要看 | 要看 |
|:-------|:-----|
| Non-GAAP净利润 | **GAAP净利润** |
| "连续两季度盈利"标题 | **盈利的环比变化**（暴跌94%） |
| 毛利率19% | **费用率趋势**（研发费用能否持续低） |
| 现金储备482亿 | **经营现金流**（融资 vs 经营） |
| "全年Non-GAAP盈利"目标 | **全年GAAP盈利**的可能性 |

### 9.2 关键验证指标（2026年剩余季度）

| 指标 | 及格线 | 优秀线 | 观察窗口 |
|:-----|:------:|:------:|:--------:|

## 十、最终结论

### 10.1 回答用户的核心问题

> **"真的盈利了吗？还是会计手法？"**

**答案**：

| 问题 | 答案 |
|:-----|:-----|
| 2025Q4真的盈利了吗？ | **真的微利了**——GAAP净利润2.83亿，但利润率仅0.8%，刀锋上的利润 |
| 2026Q1真的盈利了吗？ | **没有**——GAAP亏损3.32亿，"盈利"完全依赖Non-GAAP调整和费用削减 |
| 用了会计手法吗？ | **用了Non-GAAP口径**，但没有用研发费用资本化、收入确认操纵等更恶劣的手法 |
| 盈利质量高吗？ | **不高**—— largely "省出来"而非"赚出来"，环比暴跌94%，不可持续 |

### 10.2 一句话投资判断

> 蔚来的"盈利"是**真的开始了，但还没站稳**。毛利率改善是真实的，但"利润" largely 来自费用削减和会计调整。当研发费用从19亿回升到25亿、原材料涨价压力全面显现时，Q2-Q4的盈利将面临严峻考验。**不要为一个季度的Non-GAAP微利欢呼，等GAAP连续四个季度盈利再说。**

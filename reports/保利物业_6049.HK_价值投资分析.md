## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

保利物业是中国领先的央企物业管理服务商，控股股东为保利发展（持股72.3%），最终实际控制人为国务院国资委。公司业务采用**"物业管理服务+非业主增值服务+社区增值服务"**的轻资产模式。

- **物业管理服务**：2025年收入131.5亿元（+12.6%），占总收入76.8%，是核心基本盘。在管面积8.6亿平方米（+6.3%），覆盖住宅、商写、公建、城镇景区等多业态
- **非业主增值服务**：2025年收入16.36亿元（-16.5%），包括协销、工程、顾问等地产关联业务，主动压降中
- **社区增值服务**：2025年收入23.40亿元（-13.6%），但毛利率41.2%（+4.4pct），聚焦资产经营+社区生活服务，盈利能力提升
- **盈利驱动**：在管面积稳健增长 + 管理提效（管理费率5.8%，-1.1pct）+ 社区增值业务结构优化
- **客户结构**：关联方保利发展提供稳定项目来源，第三方外拓能力强，2025年新拓展第三方项目单年合同金额约29.3亿元

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 强 | 稳定（央企龙头、中高端定位） |
| 转换成本 | ✅ | 中 | 稳定 |
| 网络效应 | ❌ | — | — |
| 规模经济 | ✅ | 强 | 增强（在管面积8.6亿平，管理费率持续下降） |
| 牌照壁垒 | ✅ | 中 | 稳定（央企在公建/政府物业招投标中优势明显） |

**护城河评级**：**中等偏宽** — 核心优势来自：
1. **央企背景**：保利集团/保利发展是龙头央企，信用背书强，在公建、政府物业、大型项目中优势明显
2. **规模与效率**：在管面积8.6亿平，管理费率仅5.8%，运营效率行业领先
3. **关联方稳健**：保利发展虽受地产下行影响，但财务相对稳健，项目交付有保障
4. **城市名片项目**：在城镇景区、公共服务领域形成标杆项目（如深圳西涌滨海旅游度假区）

**⚠️ 护城河的挑战**：
- 毛利率持续下滑：2024年18.3% → 2025年17.4%，基础物管毛利率承压
- 增值服务收入收缩：社区增值-13.6%、非业主增值-16.5%
- 房地产下行影响增量交付：新房销售放缓影响在管面积增长
- 行业竞争加剧：市拓竞争激烈，第三方外拓金额同比略降2.5%
- 应收账款增长：2025年贸易应收款34.4亿元（+22.3%），回款压力上升

| 关联交易 | 有，基本规范 | 与保利发展关联交易占比较高，但定价公允，央企治理相对规范 |

## 六、内在价值估算

### 资产法（下行保护）

```
净现金及等价物：      ≈¥128亿
  （现金及银行结余128.9亿，有息负债极少）
+ 应收账款 × 70%：    ≈¥24亿（央企应收款质量较好，折扣较小）
+ 固定资产 × 50%：    ≈¥2亿（物业公司轻资产）
− 经营负债：          ≈¥70亿估算
= 清算价值：          ≈¥84亿（每股：≈¥15.2 / HK$16.3）
```

物业公司轻资产、现金充裕，清算价值主要依赖净现金。按PB 1.0x估算，资产支持下限约HK$115-120亿（对应股东权益约¥105-110亿）。

### 盈利法（持续经营）

采用**归母净利润**口径：

**情景A：保守（利润增长停滞）**
```
正常化净利润（2025年利润）：               ¥15.5亿
× 合理PE（8x，行业下行期）：               8x
= 盈利价值：                                ¥124亿（每股：¥22.4 / HK$24.1）
```

**情景B：中性（稳健增长）**
```
正常化净利润（2025-2026年均值）：           ¥16−17亿
× 合理PE（10x）：                           10x
= 盈利价值：                                ¥160−170亿（每股：¥28.9−30.7 / HK$31.1−33.0）
```

**情景C：乐观（利润率修复）**
```
正常化净利润（增长至18−20亿）：             ¥18−20亿
× 合理PE（12x）：                           12x
= 盈利价值：                                ¥216−240亿（每股：¥39.0−43.4 / HK$41.9−46.7）
```

### 综合内在价值：HK$160−210亿（每股HK$29−38）

取中值约 **HK$185亿** 作为参考。

**当前总市值 ≈ HK$149.40亿**

**安全边际 = (185 − 149.4) / 185 = 19.2%**

> **结论**：内在价值区间对应股价HK$29−38，当前股价HK$27.00位于区间下限附近，有一定吸引力但安全边际不足。理想买入价应在HK$19以下（对应安全边际35%+）。

## 七、能力圈判定

- **10年后最坏情况**：物业管理行业持续通缩，保利发展交付大幅减少，公司营收停滞、毛利率下滑至15%以下，年净利润回落至12-13亿，PE 8倍 → 市值约HK$100-110亿（较当前下跌25-30%）。信心度：**中低**
- **最强的反对理由**：「保利物业是央企物管龙头，背景雄厚、现金流充沛、派息稳定。8.7倍PE和6%股息率对于这样一家公司已经足够便宜。长期看，行业集中度提升利好龙头。」
- **我的回应**：
  1. 央企背景确实提供了信用和资源优势
  2. 现金流和派息稳定，是优质红利型资产
  3. 但当前PE 8.7x、PB 1.28x并未达到「极度低估」
  4. 毛利率持续下滑、增值服务萎缩是真实风险
  5. 与中海外物业（PE 6.9x、PB 1.6x、股息率6%）相比，保利物业质地更优但估值也更贵
  6. **真正的安全边际买入价**：HK$19以下（对应市值HK$105亿，安全边际43%）
- **能力圈结论**：**明确在内** — 商业模式简单，央企背景降低分析难度。当前估值合理偏低，但未达到理想买入价，建议等待。

### 买入策略
- **理想买入价**：内在价值 × 50% = HK$14−16
- **可接受买入价**：内在价值 × 70% = HK$19−21
- **当前股价**：HK$27.00（高于可接受价）
- **建议仓位上限**：B级 → **8-10%**
- **本标的建议仓位**：**0%**（当前价未到可买入区间）
- **触发买入的信号**：
  1. 股价跌至HK$21以下
  2. 2026年毛利率止跌企稳
  3. 社区增值服务收入恢复增长
  4. 应收账款增速放缓
  5. 港股物业板块情绪进一步悲观导致错杀

### 卖出触发条件
- 估值：股价 > 内在价值 × 1.1（HK$32以上）→ 考虑减仓
- 基本面：毛利率跌破15% / 净利润连续2季度下滑 / 应收账款增速远超收入增速 → 重新评估
- 管理层：大额关联交易损害小股东利益 → 清仓

### 一句话投资论文

> 以**不足的安全边际**观察一家**央企背景、质地优良的物业管理龙头**，市场因**物业行业整体悲观+毛利率下行+增值服务乏力**给予了8.7倍PE的折价，管理层**可信且派息稳定**，10年后最坏情况是**利润停滞但现金流仍能维持**，这需要**更低的买入价**（HK$19-21以下）才能接受。

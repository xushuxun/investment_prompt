## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

蔚来汽车是中国高端智能电动车企，核心差异化是**换电模式+BaaS电池租赁+极致用户服务**。采用三大品牌矩阵覆盖不同价位：

- **蔚来品牌**（30-65万）：ET5/ET7/ES6/ES8/ES9/EC6/ET9，定位高端纯电
- **乐道品牌**（20-30万）：L60/L80/L90，定位主流家庭市场
- **萤火虫品牌**（10-20万）：精品小车，2025年4月上市

**收入来源**：
- 整车销售（占85%+）：2024年582亿，毛利率12.3%
- 服务及其他（占15%）：换电服务、能源包、智能驾驶订阅、技术授权
- **BaaS模式**：用户「买车不买电池」，车价降低7-12.8万，按月付租金（728-1128元/月）

**换电网络**：
- 全国超3,700座换电站（2026年初），单站投入100-200万
- 日均60次换电可盈亏平衡，三代站日服务能力408次
- 2026年计划再建1,000座，资本开支约20亿+

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 中高（高端标签） | 分化 |
| 转换成本 | ✅ | 中（换电锁定） | 稳定 |
| 网络效应 | ⚠️ | 弱（换电网络） | 努力中 |
| 规模经济 | ❌ | 无 | 未达标 |
| 牌照壁垒 | ❌ | — | — |

**护城河评级**：**窄且脆弱** — 核心声称的壁垒：
1. **换电网络先发优势**：3,700座换电站构成实体壁垒，但这是一个**「烧钱换壁垒」**的模式，且宁德时代（巧克力换电）、国家电网等正在进入；
2. **BaaS模式创新**：降低购车门槛+电池终身质保，但本质上是**「金融杠杆+服务负债」**，电池折旧和租金可持续性存疑；
3. **用户社区/NIO House**：早期建立强用户粘性，但随规模扩大，「海底捞式服务」成本失控，已从资产变负债；
4. **高端品牌形象**：30万以上纯电市占率40%，但价格战下>40%潜在用户因价格放弃蔚来。

**⚠️ 护城河的致命裂缝**：
- **超快充技术正在侵蚀换电价值**：5C/10C超充普及后，充电10分钟续航300公里，换电的「时间优势」在缩小；
- **规模不足**：年销22万辆，仅为理想的44%，无法分摊巨额固定成本；
- **多品牌分散资源**：同时运营三个品牌+自研芯片+手机+机器人+换电站，资源极度分散；
- **用户权益成长期负债**：早期「终身免费换电」承诺，现已变成沉重成本负担。

## 三、管理层评估

**核心原则：宁要诚信普通的，不要能力强但不诚信的**

| 检验项 | 结论 | 说明 |
|:-------|:----:|:-----|
| 是否有造假/欺诈历史 | **无重大财务造假** | 未发现财报舞弊；但内部管理混乱，2025年推行CBU工时改革暴露历史问题 |
| 股东诉讼 | 无公开记录 | — |
| 关联交易 | 有 | 与大众技术合作、宁德时代合作；BaaS模式下电池资产管理公司涉及内部定价 |
| 控股比例 | **极低/存疑** | 李斌持股约8.5%（创始人股权被严重稀释）；阿布扎比CYVN持股20.1%为最大单一股东，李斌靠超级投票权(1:8)维持控制 |
| 分红/回购历史 | **无** | 从未分红，持续融资烧钱 |

**管理层评价**：**存疑/能力突出但诚信边界模糊** — 
1. **李斌的融资能力是「魔法」**：8年超20轮融资、超千亿人民币，从ICU反复救出公司（2019年合肥70亿、2023年阿布扎比237亿、2024年合肥再投33亿等），堪称中国最会「找钱」的CEO；
2. **但盈利能力是「灾难」**：盈利承诺反复跳票——2023Q4→2024→2025Q4→2026，管理层公信力严重受损；
3. **管理效率低下**：2025年被迫推行CBU（基本经营单元）改革、全员填工时，李斌自承「过去凭感性立项，浪费了太多钱」；2024年研发费用130亿（新势力最高）、销售费用157亿（历史新高），投入产出严重不匹配；
4. **股权稀释至危险水平**：创始人李斌从IPO前31.6%稀释至约8.5%，靠超级投票权维持控制，实际控制权与持股比例严重脱节；
5. **⚠️ 重大警示**：累计亏损1300亿仍未盈利，这是对股东资本最严重的「信用透支」。

## 六、内在价值估算

### 资产法（下行保护）

```
现金及等价物：        ≈¥350亿（取中间值）
+ 受限制现金/短期投资：≈¥70亿
n- 总负债：            ≈¥1,400亿（按资产负债率92.6%倒推）
= 股东权益：          ≈¥112亿

清算价值分析：
- 换电站专用资产：    清算价值≈0（土地租赁+定制设备，无法变现）
- 库存车辆/零部件：    约¥200亿，清算打5折 = ¥100亿
- 应收账款：          约¥100亿，清算打7折 = ¥70亿
- 无形资产/品牌：      清算价值≈0
- 减：优先债务/供应商应付款：约¥800亿
n= 清算价值：          ≈-¥280亿（股东回收为负）
```

⚠️ **蔚来的清算价值为负**。这意味着如果公司破产清算，股东不仅拿不回钱，还可能倒欠债务。当前1,020亿市值完全建立在「未来能盈利」的故事上。

### 盈利法（持续经营）

由于公司从未盈利且亏损规模巨大，只能做极端假设：

**情景A：悲观（长期无法盈利，现金流断裂）**
```
合理价值：¥0（破产清算，股权归零）
```

**情景B：中性（2028年实现微利）**
```
假设2028年营收1,500亿，净利率3% = ¥45亿净利润
× 合理PE（10x，制造业周期股）：  10x
= 盈利价值：                     ¥450亿（每股：≈HK$19.5）
```

**情景C：乐观（成为「换电版特斯拉」）**
```
假设2028年营收2,000亿，净利率5% = ¥100亿净利润
× 合理PE（15x，成功故事）：       15x
= 盈利价值：                     ¥1,500亿（每股：≈HK$65）
```

## 七、能力圈判定

- **10年后最坏情况**：超快充技术全面普及→换电模式被边缘化→巨额换电站资产沦为沉没成本→持续亏损导致现金流断裂→破产清算或被低价收购→股东权益归零。信心度：**高**
- **最强的反对理由**：「换电网络是万亿级的能源基础设施，一旦形成规模就是无法复制的护城河；BaaS模式重塑了汽车所有权结构；蔚来在30万以上高端市场有品牌壁垒；李斌总能找到钱让公司活下去；累计1亿次换电证明模式可行。」
- **我的回应**：
  1. **换电的「护城河」是用1300亿亏损换来的**，这不是护城河，这是资本的坟场；
  2. 加油站之所以能盈利是因为所有车都加油，而换电站只服务蔚来体系（+少数盟友），**网络效应有限**；
  3. 宁德时代、国家电网等正在布局标准化换电，**蔚来的「自定义标准」可能被统一标准取代**；
  4. 李斌「总能找到钱」不是优点——**如果商业模式健康，不应需要8年20轮融资**；
  5. 丰田、大众等百年车企的净利率仅5-8%，蔚来凭什么在实现规模后获得更高利润？
  6. **最关键：即使故事全部兑现，当前估值也已在乐观假设的上限，没有安全边际。**
- **能力圈结论**：**明确在外** — 一家累计亏损1300亿、资产负债率92.6%、盈利遥遥无期、技术路线存疑的烧钱企业，远超传统价值投资者的能力圈和安全边际要求。

| **综合评级** | **D-（强烈回避）** | **D（回避）** | **C+（观察）** | **D（回避）** |

**核心结论**：
- **蔚来是本系列分析的四家企业中「最危险」的一家**。它不仅「贵」（PB 25.9倍），而且「濒临破产」（资产负债率92.6%、累计亏损1300亿、净资产几乎耗尽）；
- 与小鹏相比：两者都亏损，但小鹏毛利率持续改善（18.9%→21.3%）、现金476亿、负债可控；蔚来毛利率低（9.9%）、亏损扩大、负债极高；
- 与长城汽车相比：长城虽然生意质量一般，但**有盈利、低估值、高股息、优秀管理层**，是「可以观察等待」的标的；蔚来是「即使腰斩再腰斩也不能碰」的标的；
- **李录框架的终极启示**：「不要亏钱」是第一原则。蔚来的资产负债表显示，这家公司正在以每年200亿+的速度毁灭股东资本，且已持续了8年。无论故事多么动人，持续毁灭资本的企业最终会让股东血本无归。

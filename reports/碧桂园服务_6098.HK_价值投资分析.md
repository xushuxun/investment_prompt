## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

碧桂园服务是中国规模最大的民营物业管理服务商之一，采用**"大物业+社区增值服务+城市服务"**的轻资产模式。

- **物业管理服务**：2024年收入259.1亿元，占总收入58.9%；2025年大物业板块收入331.2亿元（+6.2%），占总收入约70%。在管面积超11亿平方米（含三供一业），管理项目近8,000个
- **三供一业**：2024年收入约65亿元，2025H1收入50.7亿元（+51.6%），成为重要增长极
- **社区增值服务**：2024年收入41.9亿元（+11.8%），包括酒类、充电桩（"智享楼下充电"）、新零售等
- **非业主增值服务**：主动压降高风险客户，关联方收入占比已从2018年20.3%降至2024/2025年的1.1%
- **城市服务/商业运营**：2024年收入有所收缩，2025年战略调整中
- **盈利驱动**：规模效应 + 社区增值服务 + 三供一业扩张；但毛利率持续承压

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 中 | 稳定（行业龙头） |
| 转换成本 | ✅ | 中 | 稳定 |
| 网络效应 | ❌ | — | — |
| 规模经济 | ✅ | 强 | 增强（在管面积行业前列） |
| 牌照壁垒 | ❌ | — | — |

**护城河评级**：**中等** — 核心优势来自：
1. **规模龙头**：在管面积超11亿平，管理项目近8,000个，覆盖五大城市群
2. **品牌与效率**：头部物企中品牌认知度高，人均管理面积持续提升
3. **社区增值服务生态**：充电桩、酒类等业务探索新增长点
4. **三供一业**：央企后勤社会化改革受益者，2025H1增速超50%

**⚠️ 护城河的挑战**：
- 毛利率持续下滑：2024年19.2% → 2025H1 18.5% → 2025全年17.5%，行业价格战与成本上升双重挤压
- 应收账款高企：2024H1末贸易应收款原值219.6亿元，净应收账天数157天，行业最高水平之一
- 关联方风险：虽然关联方收入占比仅1.1%，但大股东碧桂园控股债务危机仍可能通过资金占用、应收款回收等方式传导
- 商誉/无形资产减值：前期大规模并购带来减值压力

## 三、管理层评估

**核心原则：宁要诚信普通的，不要能力强但不诚信的**

| 检验项 | 结论 | 说明 |
|:-------|:----:|:-----|
| 是否有造假/欺诈历史 | **无重大造假** | 未发现财务造假，但存在关联交易争议 |
| 股东诉讼 | 有争议 | 大股东债务危机引发中小股东担忧 |
| 关联交易 | **存疑** ⚠️ | 2025年5月向杨惠妍提供10亿元贷款，以其持股16.26%股份抵押 |
| 控股比例 | **高** | 杨惠妍家族通过碧桂园控股控制约36%+股份 |
| 分红/回购历史 | **优秀（表面）** | 2025年派息率60%，全年派息15.11亿元；持续回购 |
| 资本配置 | **存疑** | 高派息+回购虽利好股东，但10亿关联借款损害公司治理 |

**管理层评价**：**存疑（C+）** — 核心问题：
1. **大股东债务危机**：碧桂园控股2022-2024年累计亏损超2,000亿元，虽已债务重组，但经营仍脆弱
2. **资金占用风险**：2025年5月，碧桂园服务向杨惠妍提供10亿元贷款，年利率5%，以杨惠妍持有的16.26%公司股份为抵押。虽然形式上有抵押，但本质是上市公司资金被大股东占用，引发市场对公司治理的担忧
3. **高派息的可持续性**：60%派息率需要稳定现金流支撑，若应收款回收恶化或关联方进一步占用资金，派息可能承压
4. **正面因素**：管理层积极推动业务独立化，关联方收入占比降至1.1%；数字化、机器人等降本举措推进

**这是本标的最核心的风险点**：管理层能力不弱，但大股东诚信和资本配置取向值得警惕。

## 四、为什么便宜？（市场误判分析）

**这是最重要的问题——如果真的便宜，市场在担心什么？这个担心成立吗？**

| 市场担心的 | 实际情况 | 是否成立 |
|:-----------|:---------|:--------:|
| 大股东碧桂园控股债务危机 | 碧桂园控股2022-2024年累计亏损超2,000亿，虽已债务重组但经营仍脆弱 | **是** |
| 关联资金占用 | 2025年5月向杨惠妍借款10亿元，以股份抵押 | **是** |
| 应收账款回收风险 | 贸易应收款原值219.6亿，净应收天数157天，减值比例上升 | **是** |
| 毛利率持续下滑 | 2024年19.1% → 2025年17.5%，行业价格战未结束 | **是** |
| 商誉/无形资产减值 | 前期并购带来减值压力，2022-2023年已大额计提 | **部分** |
| 物业费降价与收缴率下降 | 行业普遍压力，三四线城市空置率高 | **部分** |
| 民营物企板块整体悲观 | 港股市场对民营房企关联物企极度厌恶 | **是** |

**我的信息优势/独特视角**：
- 市场可能过度恐慌：碧桂园服务第三方收入占比领先，关联方收入仅1.1%，业务独立性较强
- 现金流确实充沛：179亿现金、25.1亿经营现金流、60%派息率、持续回购
- 但**10亿关联借款事件**表明大股东仍可能继续占用上市公司资源，这是价值投资者无法忽视的红线
- 这不是「市场严重误判」，而是「风险折价」——折价幅度大，但风险真实存在

## 六、内在价值估算

### 资产法（下行保护）

```
净现金及等价物：      ≈¥129亿
  （现金及存款179.3亿 − 有息负债约50亿估算）
+ 应收账款 × 50%：    ≈¥60亿（物业应收款回收风险高，折扣较大）
+ 固定资产 × 30%：    ≈¥3亿（物业公司轻资产）
− 总负债（经营负债）： ≈¥150亿估算
= 清算价值：          ≈¥42亿（每股：≈¥1.3 / HK$1.4）
```

⚠️ 碧桂园服务的资产法价值有限：现金充裕但应收款规模大、质量存疑，且大股东占用风险使现金安全性打折。**资产法下行保护不足。**

更可靠的资产参照：股东权益约¥367亿（按PB 0.42x反推），但需考虑应收账款减值和关联方占用的侵蚀。

### 盈利法（持续经营）

采用**核心净利润**口径（剔除非经常性减值影响）：

**情景A：保守（周期低谷利润）**
```
正常化核心净利润（2025年已实现）：          ¥25.2亿
× 合理PE（6x，高风险折价）：                6x
= 盈利价值：                                ¥151亿（每股：¥4.6 / HK$5.0）
```

**情景B：中性（核心利润企稳）**
```
正常化核心净利润（2025-2026年均值）：        ¥25−27亿
× 合理PE（8x）：                            8x
= 盈利价值：                                ¥200−216亿（每股：¥6.1−6.6 / HK$6.6−7.1）
```

**情景C：乐观（利润回升+风险缓释）**
```
正常化核心净利润（恢复到30亿+）：            ¥30亿
× 合理PE（10x，不给予高溢价）：              10x
= 盈利价值：                                ¥300亿（每股：¥9.2 / HK$9.9）
```

### 综合内在价值：HK$180−280亿（每股HK$5.5−8.6）

取中值约 **HK$230亿** 作为参考。

**当前总市值 ≈ HK$165.85亿**

**安全边际 = (230 − 165.85) / 230 = 27.9% ≈ 28%**

> **注意**：若考虑管理层诚信折价（关联借款、潜在进一步资金占用），合理内在价值应下调至HK$180−200亿，对应安全边际降至8−18%。

## 七、能力圈判定

- **10年后最坏情况**：大股东碧桂园控股持续占用上市公司资金→应收账款坏账爆发→商誉/无形资产进一步减值→公司沦为「大股东提款机」，核心净利润回落至15-20亿，PE 5倍→市值约HK$100-130亿（较当前下跌20-40%）。信心度：**中**
- **最强的反对理由**：「碧桂园服务第三方收入占比高、现金充裕、派息率高、PB 0.42倍已经过度悲观。只要大股东不再伸手，仅凭现金流和派息就值这个价。10%股息率足以补偿风险。」
- **我的回应**：
  1. 现金流和派息确实诱人，但**大股东已经伸手了**（2025年10亿借款）
  2. 物业行业整体下行，毛利率未见底
  3. 应收账款219.6亿原值，净应收天数157天，是潜在雷区
  4. 高派息可能是为了安抚大股东（通过分红权偿还借款），而非完全出于小股东利益
  5. 对民营房企关联物企，李录框架下「管理层可信」这一关很难过
  6. **能力圈结论**：商业模式能理解，但管理层诚信问题超出舒适区
- **能力圈结论**：**边缘** — 估值便宜且现金流清晰，但公司治理风险使信心不足。若股价跌至HK$4.0以下（对应市值HK$130亿，安全边际43%），可小仓位参与；否则以观察为主。

## 八、投资结论

| 项目 | 结论 |
|:-----|:-----|
| **投资建议** | **观察/小仓位买入**（高风险偏好） |
| 生意质量 | 中等（B） |
| 估值水平 | 低估（按核心利润和股息） |
| 管理层 | **存疑（C+）** |
| 综合评级 | **C+** |

### 买入策略
- **理想买入价**：内在价值 × 50% = HK$2.8−3.5
- **可接受买入价**：内在价值 × 70% = HK$4.0−4.5
- **当前股价**：HK$5.09（高于可接受价）
- **建议仓位上限**：C+级 → **≤3%**
- **本标的建议仓位**：**0-2%**（仅作为高股息烟蒂配置）
- **触发买入的信号**：
  1. 股价跌至HK$4.0以下
  2. 大股东明确承诺不再新增关联借款并实际遵守
  3. 应收账款净天数开始下降
  4. 毛利率止跌回升（稳定在17%以上）
  5. 2026年派息率维持60%且现金流覆盖派息

### 卖出触发条件
- 估值：股价 > 内在价值 × 1.0（HK$5.5以上）→ 考虑减仓
- 基本面：新增关联资金占用 / 应收账款减值大幅扩大 / 毛利率跌破15% → 清仓
- 公司治理：大股东质押比例上升或进一步借款 → 清仓

### 一句话投资论文

> 以**约28%的安全边际**观察一家**现金流充裕但公司治理存疑的民营物管龙头**，市场因**大股东债务危机+关联借款+应收款风险**给予了PB 0.42倍和10%股息率的折价，管理层**诚信记录有污点**，10年后最坏情况是**沦为大股东提款机利润腰斩**，这需要**更低的买入价**（HK$4以下）或**管理层诚信改善**才能接受。

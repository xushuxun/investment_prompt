## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

- **高端纯电整车**：NIO主品牌定位30-60万元，2026Q1成交均价约39万元，在一线城市高端纯电市场份额领先。
- **BaaS电池租用服务**：车电分离，用户按月付电池租金，降低购车门槛；电池资产出售给武汉蔚能并表/关联公司。
- **多品牌下探**：
  - ONVO乐道：家庭用车品牌，L60对标Model Y；
  - firefly萤火虫：精品小型车，2025年4月交付。
- **能源服务（NIO Power）**：可充可换可升级，截至2026-08-28全国换电站4,041座、充电桩30,021根。
- **用户运营**：NIO House、NIO Life周边，构建高粘性社区。

2026Q1财务转折信号：营收255.3亿（+112%），交付8.35万辆（+98%），综合毛利率19.0%，**GAAP净亏损仅4.96亿**，经调整经营利润已转正。

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | 部分（高端纯电有溢价，但多品牌稀释） | 中 | 走弱 |
| 转换成本 | 弱（BaaS/换电有一定锁定，但不强） | 弱 | 稳定 |
| 网络效应 | 无 | — | — |
| 规模经济 | 部分（交付从22万→33万→2026冲刺50万） | 中 | 增强 |
| 牌照/标准壁垒 | **换电网络**（4,041座）+ **换电联盟**（长安/吉利/江淮/奇瑞/广汽/一汽） | 中 | 待定 |

**护城河评级：窄（且未验证）** — 换电网络是蔚来最独特的资产，但它目前是**现金消耗型基础设施**而非盈利护城河。真正的护城河只有在两种情况下成立：① 换电成为行业主流标准且联盟车企大规模量产换电车型；② 换电站单站日均服务量突破盈亏平衡点（约50-60次/天）。截至2026年4月，**联盟车企尚无一款量产换电车型上市**。

## 三、管理层评估

**核心原则：宁要诚信普通的，不要能力强但不诚信的**

| 检验项 | 结论 | 说明 |
|:-------|:----:|:-----|
| 是否有造假/欺诈历史 | ⚠️ 有争议，无终审 | 2022年灰熊做空质疑BaaS收入确认；2025年GIC起诉蔚来通过蔚能虚增约6亿美元收入，目前暂缓审理等待集体诉讼结果；蔚来独立调查否认 |
| 股东诉讼 | 有 | GIC证券欺诈诉讼、相关集体诉讼进行中 |
| 关联交易 | 有 | 武汉蔚能电池资产公司（BaaS模式核心），GIC指控存在收入确认问题；与关联方应收款高达163.8亿（2026Q1） |
| 控股比例 | 7.1%股权 / 34%投票权 | 李斌通过C类股掌握超级投票权；两次增发后股权被稀释 |
| 分红/回购历史 | 无 | 从未分红、无回购；持续融资（2025年闪电配售+11.6亿美元增发） |
| 股权激励 | ⚠️ 巨额 | 2026年3月向李斌授予约2.48亿股零对价RSU，归属条件为市值300-1200亿美元及净利润15-60亿美元 |

**管理层评价：存疑** — 李斌有远见、用户运营能力强，且2026Q1经营层面确有改善。但：① BaaS会计争议悬而未决；② 持续大额稀释小股东；③ 给自己零对价巨额股权激励；④ 十年累计亏损超800亿且多数年份自由现金流为负。这不是李录框架下值得信赖的资本配置者。

## 六、内在价值估算

### 资产法（下行保护）

```
净现金（现金储备482 − 有息借款146.8）：    +335.2
+ 应收账款类 175.4 × 80%：                 +140.3
+ 存货 85.8 × 60%：                        +51.5
+ 固定资产 254.3 × 40%：                   +101.5
− 经营性负债（总负债1,117 − 有息146.8）：  −970.2
= 清算价值：                                ≈ −342亿（为负）
```

清算价值为负。归母股东权益仅43.4亿，而市值777亿——**PB 17x意味着市场给的是「未来权益增长」的期权，而非当前资产价值**。

### 盈利法（持续经营）

```
近6年归母净利均值 = (-56.1-105.7-145.6-211.5-226.6-155.7)/6 ≈ -150亿
历史均值为负，无法估值。

情景参考（非内在价值）：
若2026-2027年成功实现年交付50万辆、ASP 30万、综合毛利率18%、
经营费用率降至15%以下 → 经营利润约60-80亿，税后约50-65亿
× 10x = 500-650亿 ≈ 20-26港元/股
```

这一结果完全依赖「扭亏成功」假设链，且未考虑巨额可转债潜在稀释。在李录框架下，**不能用假设估值**。

### 综合内在价值：**无法可靠估算**

**安全边际 = 无法计算** — 对一家累计亏损超800亿、权益仅剩43亿、仍处盈亏边缘的公司，不存在可计算的安全边际。

## 七、能力圈判定

- **10年后最坏情况**：换电网络未能成为行业标准，蔚来独自承担重资产成本导致持续失血；多品牌在10-30万价格带被比亚迪/吉利/小米压制；NIO主品牌高端份额被华为系/理想/极氪蚕食；公司不断融资稀释股东，最终沦为二线车企或被低价收购。信心度：**中高**
- **最强的反对理由**：蔚来2026Q1已经逼近盈亏平衡，毛利率19%创纪录，交付量同比翻倍；换电网络一旦开放给联盟车企将形成平台级护城河；NIO Power单独融资/出售控股权可释放价值。
- **我的回应**：反对理由可能是对的，但它依赖太多未证实假设。李录框架不为「如果」付费；而且BaaS会计争议和管理层自授巨额RSU侵蚀了治理信任。
- **能力圈结论：在外** — 这不是我能用价值投资方法分析并下注的生意。

## 八、投资结论

| 项目 | 结论 |
|:-----|:-----|
| **投资建议** | **回避** |
| 生意质量 | 差（有独特资产但未盈利） |
| 估值水平 | 高估（PB 17x，为亏损和期权付费） |
| 管理层 | 存疑 |
| 综合评级 | **D** |

### 买入策略
- **理想买入价**：无法给出可靠值；若强行按扭亏后65亿×10x = 650亿 ≈ 26港元，再折50% ≈ **13 港元**
- **可接受买入价**：按同一乐观假设×70% ≈ **18 港元**
- **建议仓位上限**：D级 — **0%**
- **本标的建议仓位**：不配置。只有当公司连续四个季度GAAP盈利、BaaS/GIC争议落地、不再依赖股权融资时，才重新纳入观察。

### 卖出触发条件
- 估值：当前即应避免买入；若已持有，PB > 10x且仍未盈利 → 减仓/清仓；
- 基本面：季度亏损重新扩大、现金储备跌破300亿、换电联盟合作破裂、NIO Power出售价格显著低于预期 → 清仓；
- 信号：当「换电成为行业标准」成为散户共识、媒体热度极高时——参考添柏岚卖出逻辑。

### 一句话投资论文
> 蔚来拥有中国车企中最独特的换电网络和用户运营体系，但它累计亏损超800亿、归母权益仅剩43亿、PB 17x、BaaS会计争议悬而未决，且管理层持续稀释股东——按李录价值投资纪律，这是一家应坚决回避的公司，无论其故事多么诱人。

## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

中海物业是中国领先的物业管理服务商，隶属中国建筑集团旗下中国海外集团，采用**"基础物管+增值服务+城市运营"**的轻资产模式。

- **物业管理服务**：2025年收入117.3亿元（+9.1%），占总收入78.4%，毛利率14.3%。在管面积4.78亿平方米（+8.0%），覆盖住宅、商写、医院、学校、政府物业、城市服务等16个业态
- **住户增值服务**：2025年收入12.2亿元（-12.0%），毛利率34.0%（+8.5pct），包括社区资产经营、居家生活服务、商业服务运营
- **非住户增值服务**：2025年收入19.4亿元（+6.1%），毛利率7.2%（-5.9pct），包括工程服务、交付前服务、顾问咨询等
- **停车位买卖业务**：2025年收入0.72亿元，出售车位1,037个
- **城市运营服务**：2025年收入24.3亿元（+24.8%），占物管收入20.7%，是战略转型重点方向
- **盈利驱动**：在管面积稳健增长 + 非住宅/城市运营占比提升 + 数字化降本（人均管理面积两年提升34%）
- **客户结构**：关联方（中建及中国海外集团）占比57.3%，独立第三方占比42.7%，市场化拓展能力增强

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 强 | 稳定（央企背景、中高端定位） |
| 转换成本 | ✅ | 中 | 稳定（更换物管涉及业主表决，成本高） |
| 网络效应 | ❌ | — | — |
| 规模经济 | ✅ | 中 | 增强（人均效能持续提升） |
| 牌照壁垒 | ✅ | 中 | 稳定（政府/公建项目偏好央企） |

**护城河评级**：**中等偏窄** — 核心优势来自：
1. **央企品牌与信用背书**：中国海外集团控股61.2%，在公建、医院、学校、政府物业招投标中优势明显
2. **中高端住宅物管口碑**：客户满意度91分，处于行业90分位以上
3. **规模与效率**：在管面积4.78亿平，销管费率仅2.8%，人均管理面积12,555平/人，行业领先
4. **关联方资源**：中国海外发展、中海宏洋等稳健房企提供稳定项目来源

**⚠️ 护城河的挑战**：
- 物业费降价压力：多地出台物业费指导价，行业价格战加剧
- 收缴率下降：地产下行周期中业主缴费意愿减弱
- 毛利率下滑：2024年16.6% → 2025年15.0%，基础物管毛利率14.3%（-1.6pct）
- 应收账款减值增加：减值比例由8.6%升至11.1%，2025年金融资产减值1.28亿元
- 房地产新开工下滑影响增量交付，内生增长放缓

## 六、内在价值估算

### 资产法（下行保护）

```
净现金及等价物：      ≈¥60亿
  （总现金约64.4亿港元，扣除极少有息负债）
+ 应收账款 × 70%：    ≈¥22亿（物管应收账期相对可控，折扣较小）
+ 固定资产 × 50%：    ≈¥1.5亿（物业公司轻资产，固定资产占比低）
− 总负债：            ≈¥1.5亿
= 清算价值：          ≈¥82亿（每股：≈¥2.5 / HK$2.7）
```

物业公司是**典型轻资产**行业：现金充裕、负债极低、清算价值接近净资产。按PB 1.0x估算，资产支持下限约HK$67-75亿。

### 盈利法（持续经营）

采用**三种情景**：

**情景A：保守（周期低谷利润）**
```
正常化净利润（2025年利润/2026年预测）：    ¥12−13亿
× 合理PE（8x，行业下行期）：               8x
= 盈利价值：                                ¥96−104亿（每股：¥2.9−3.2 / HK$3.1−3.4）
```

**情景B：中性（平均利润）**
```
正常化净利润（近5年平均/股权激励目标）：    ¥13−14.5亿
× 合理PE（10x）：                           10x
= 盈利价值：                                ¥130−145亿（每股：¥4.0−4.4 / HK$4.3−4.7）
```

**情景C：乐观（利润回升）**
```
正常化净利润（2024年高点/城市运营放量）：   ¥15−16.5亿
× 合理PE（12x）：                           12x
= 盈利价值：                                ¥180−198亿（每股：¥5.5−6.0 / HK$5.9−6.5）
```

### 综合内在价值：HK$140−170亿（每股HK$4.3−5.2）

取中值约 **HK$155亿** 作为参考。

**当前总市值 ≈ HK$108.7亿**

**安全边际 = (155 − 108.7) / 155 = 29.9% ≈ 30%**

> **核心变量**：若物业费降价与收缴率风险可控，公司利润稳定在13-14亿水平，当前估值具备明显吸引力；若行业进一步恶化导致利润跌至10亿以下，安全边际将收窄。

## 七、能力圈判定

- **10年后最坏情况**：物业管理行业持续通缩，物业费普遍降价20-30%，收缴率大幅下滑，公司利润率被压缩至5%以下，年利润降至7-8亿，PE 8倍 → 市值约HK$60-70亿（较当前下跌35-45%）。信心度：**中**
- **最强的反对理由**：「中海物业是央企物管龙头，品牌、信用、效率优势明显，现金流稳定且派息率高。6.9倍PE和6%股息率已经过度反映了行业悲观预期。城市运营业务高速增长，长期空间广阔。」
- **我的回应**：
  1. 央企背景确实提供了信用背书和公建项目获取优势
  2. 轻资产模式资本开支少、ROCE高，是较好的生意形态
  3. 但物业行业整体处于下行周期，物业费降价、收缴率压力、应收账款减值是真实存在的风险
  4. 2025年净利润下滑9.7%、毛利率下滑1.6pct，说明行业压力已经传导至报表
  5. 6.9倍PE虽然便宜，但如果利润继续下滑，估值陷阱风险存在
  6. **结论**：在HK$3.0-3.3区间可以小仓位建仓，但需预留加仓空间，不宜重仓
- **能力圈结论**：**明确在内** — 物业管理商业模式简单易懂，央企背景降低分析复杂度。当前估值进入可投资区间，但行业处于周期底部，需持续跟踪季度数据。

## 八、投资结论

| 项目 | 结论 |
|:-----|:-----|
| **投资建议** | **买入/观察**（H股） |
| 生意质量 | 良好（B+） |
| 估值水平 | 低估 |
| 管理层 | 良好（B+） |
| 综合评级 | **B** |

### 买入策略
- **理想买入价**：内在价值 × 50% = HK$2.3−2.5
- **可接受买入价**：内在价值 × 70% = HK$3.2−3.4
- **当前股价**：HK$3.31（接近可接受买入价）
- **建议仓位上限**：B级 → **8-10%**
- **本标的建议仓位**：**5-8%**（行业周期底部，保守配置）
- **触发加仓的信号**：
  1. 股价跌至HK$3.0以下
  2. 2026年中报净利润环比企稳或回升
  3. 毛利率止跌（维持在14%以上）
  4. 城市运营收入保持20%以上增速
  5. 应收账款减值不再扩大

### 卖出触发条件
- 估值：股价 > 内在价值 × 1.2（约HK$5.0）→ 考虑减仓
- 基本面：毛利率跌破12% / 净利润连续2季度下滑超15% / 应收账款减值大幅扩大 → 重新评估
- 管理层：大额关联交易损害小股东利益 / 派息率显著下降 → 清仓

### 一句话投资论文

> 以**约30%的安全边际**买入一家**央企背景、轻资产、高ROCE的物业管理公司**，市场因**物业行业整体悲观预期**给予了6.9倍PE的折价，管理层**稳健且派息慷慨**，10年后最坏情况是**利润率压缩但现金流仍能维持**，这是一个**可以小仓位接受的周期底部机会**。

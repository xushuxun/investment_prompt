## 七、内在价值估算（更新）

### 7.1 资产法（下行保护）

```
现金及等价物：        ≈¥482亿（Q1末，持续改善）
+ 受限制现金/短期投资：≈¥70亿
- 总负债：            ≈¥1,400亿（资产负债率92.6%）
= 股东权益：          ≈¥112亿（仍极低）

清算价值分析：
- 换电站专用资产：    清算价值≈0（但运营中开始产生正现金流）
- 库存车辆/零部件：    约¥200亿，清算打5折 = ¥100亿
- 应收账款：          约¥100亿，清算打7折 = ¥70亿
- 无形资产/品牌：      清算价值≈0
- 减：优先债务/供应商应付款：约¥800亿
= 清算价值：          ≈-¥280亿（股东回收仍为负）
```

⚠️ **清算价值仍为负**，但**持续经营现金流已转正**，破产风险边际降低。

```

```


## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

长城汽车是中国领先的民营车企，采用**"多品牌矩阵+垂直整合+全球化"**模式，收入来源以整车销售为主（占比>90%）。

- **五大品牌**：
  - **哈弗**：SUV基本盘，2025年销量75.8万辆（+7.4%），均价约12-15万
  - **坦克**：硬派越野高端化，2025年销量23.3万辆（均价28.6万，毛利率最高）
  - **魏牌**：高端新能源，2025年销量10.2万辆（+86.2%），直营转型中
  - **欧拉**：纯电女性市场，2025年销量4.8万辆（-23.6%），下滑明显
  - **长城皮卡**：国内市占率>40%，绝对龙头，2025年销量18.2万辆
- **盈利驱动**：坦克/皮卡等高毛利车型占比提升 → 单车均价14.8万，高于吉利（10.2万）
- **销售模式**：传统经销商为主，魏牌拓展直营（推高销售费用）
- **海外布局**：2025年海外销量50.6万辆（+11.6%），占总销量38.2%；拥有泰国、巴西等海外工厂

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | ✅ | 中 | 分化（坦克强，欧拉弱） |
| 转换成本 | ❌ | — | — |
| 网络效应 | ❌ | — | — |
| 规模经济 | ✅ | 中 | 稳定 |
| 牌照壁垒 | ❌ | — | — |

**护城河评级**：**窄→中等** — 核心优势来自**细分品类的专业壁垒**：
1. **坦克在硬派越野市场**：2023年市占率55%，品牌与越野文化深度绑定，短期难被颠覆；
2. **皮卡绝对龙头**：国内市占率>40%，风骏/长城炮产品线齐全；
3. **SUV基因**：哈弗H6曾长期销冠，但近年被比亚迪宋等超越，基本盘承压；
4. **垂直整合**：自研Hi4/Hi4-T混动、柠檬平台、Coffee Pilot智驾，供应链自控能力强。

**⚠️ 护城河的挑战**：
- 新能源转型滞后：2025年新能源销量40.4万辆，占比仅30.5%，远低于比亚迪（100%）和吉利（>40%）；
- 欧拉品牌萎缩（-23.6%），纯电路线竞争力不足；
- 汽车行业价格战激烈，差异化护城河在「性价比」面前被削弱。

## 三、管理层评估

**核心原则：宁要诚信普通的，不要能力强但不诚信的**

| 检验项 | 结论 | 说明 |
|:-------|:----:|:-----|
| 是否有造假/欺诈历史 | **无** | 未发现重大违规或监管处罚记录 |
| 股东诉讼 | 无公开记录 | — |
| 关联交易 | 有，基本规范 | 2024年收购天孚之星少数股权等，经股东大会审议 |
| 控股比例 | **高** | 魏建军通过创新长城等间接持股约58%+，控制力强，与股东利益深度绑定 |
| 分红/回购历史 | **优秀** | 历史分红募资比**815.7%**；2024年度分红率30.34%（约38.5亿）；曾多次回购股份 |

**管理层评价**：**优秀（A-）** — 魏建军是中国汽车业最资深的民营企业家之一（1990年加入，35年深耕），核心亮点：
1. **长期主义**：拒绝参与恶性价格战，坚持「价值战」而非「流量战」；
2. **资本配置理性**：分红大方，回购积极，不盲目圈钱；
3. **技术投入坚决**：研发投入连续3年超百亿，垂直整合供应链；
4. **减分项**：魏牌直营转型推高销售费用（2025年销售费用+43.9%），部分战略摇摆（欧拉品牌定位窄、纯电路线落后）。

## 四、为什么便宜？（市场误判分析）

**这是最重要的问题——如果真的便宜，市场在担心什么？这个担心成立吗？**

| 市场担心的 | 实际情况 | 是否成立 |
|:-----------|:---------|:--------:|
| 新能源转型滞后 | 新能源占比仅30.5%，纯电（欧拉）下滑，落后比亚迪/吉利 | **是** |
| 价格战侵蚀利润 | 2025年毛利率18%（-1.47pct），净利率4.4%，行业竞争白热化 | **是** |
| 哈弗基本盘失守 | H6被比亚迪宋等超越，SUV龙头地位动摇 | **部分** |
| 直营转型费用激增 | 2025年销售费用+43.9%至112.7亿，侵蚀利润 | **是** |
| 出口增长放缓 | 2025年海外销量+11.6%（vs 2024年更高增速），海外毛利率下降2pct | **部分** |
| 2026年目标过于激进 | 销量目标180万辆（+36%），国内需+47%，完成难度大 | **部分** |

**我的信息优势/独特视角**：
- H股PE 8倍、PB 0.9倍、股息率4.7%，**表面看是「低估值」**；
- 但市场的担忧有合理性：新能源转型慢、价格战看不到尽头、利润刚经历22%的下滑；
- **这不是「市场严重误判」，而是「周期下行中的合理折价」**；
- 如果长城能在坦克+皮卡+出口的差异化路线上守住利润，同时Hi4混动技术放量，当前估值有修复空间；但如果价格战继续恶化，8倍PE仍有下修空间。

## 六、内在价值估算

### 资产法（下行保护）

```
净现金及等价物：      ≈¥258亿
+ 应收账款 × 60%：    ≈¥120亿（整车企业应收账期长，折扣大）
+ 存货 × 50%：        ≈¥100亿（产成品+在制品，汽车存货贬值风险）
+ 固定资产 × 30%：    ≈¥150亿（工厂设备专用性强，清算价值低）
- 总负债：            ≈¥1,320亿
= 清算价值：          ≈-¥692亿（每股：≈-¥8）
```

⚠️ 汽车制造业是典型的**负清算价值**行业：高负债、重资产、存货和应收账款在清算时大幅贬值。**不要以PB<1作为买入理由。**

### 盈利法（持续经营）

采用**三种情景**：

**情景A：保守（周期低谷利润）**
```
正常化净利润（取近5年较低值）：  ¥75亿（假设价格战持续，利润压缩）
× 合理PE（8x，制造业周期股）：   8x
= 盈利价值：                     ¥600亿（每股：¥7.0）
```

**情景B：中性（平均利润）**
```
正常化净利润（近5年均值）：      ¥89亿
× 合理PE（10x）：                10x
= 盈利价值：                     ¥890亿（每股：¥10.4）
```

**情景C：乐观（利润回升）**
```
正常化净利润（2024年高点）：     ¥127亿
× 合理PE（10x，不给予高溢价）：  10x
= 盈利价值：                     ¥1,270亿（每股：¥14.8）
```

### 综合内在价值（公司总市值口径）：¥750–¥1,000亿

取中值约 **¥850亿** 作为参考。

**当前公司总市值（A+H）≈ ¥1,400亿**

**安全边际 = (850 - 1,400) / 850 = -65%**

> **注意**：如果只看H股，H股市值820亿已接近中性内在价值（850亿）的**上限**。但H股股东享有的是整个公司的利润，不能将H股单独估值为「便宜」。

> 更准确的H股视角：若公司总价值850亿合理，H股按市值比例约值¥290亿（按H股折价惯例），当前H股市值820亿，**并不便宜**。

> 但如果用「H股PE 8倍」反推：若未来净利润能回升至120亿+，当前H股估值具备一定吸引力。**核心变量是利润能否回升。**

## 七、能力圈判定

- **10年后最坏情况**：新能源转型失败→哈弗基本盘被比亚迪/吉利蚕食→坦克被竞品模仿分流→出口受地缘政治限制→公司沦为二三线车企，年利润30-50亿，PE 6倍→市值200-300亿（当前1/5到1/7）。信心度：**中**
- **最强的反对理由**：「坦克+皮卡的差异化护城河足够深，魏建军是穿越周期的企业家，H股PE 8倍、PB 0.9倍、股息率4.7%，已经是市场过度悲观。只要汽车行业不崩盘，这个估值下行空间有限，上行空间可观。」
- **我的回应**：
  1. 坦克的越野壁垒确实深（文化+技术+改装生态），但比亚迪方程豹、福特Bronco等竞品正在涌入；
  2. 皮卡受政策限制（城市限行），增长天花板可见；
  3. 汽车价格战如果持续3年以上，即使强如丰田也会被侵蚀利润；
  4. 8倍PE不是「极度低估」，只是「合理偏低」——制造业周期股在下行期本就该给低估值；
  5. **真正的安全边际买入价**：总公司在¥600亿以下（对应H股约HK$7.5以下）。
- **能力圈结论**：**明确在内** — 汽车制造业可以理解，但当前估值未提供足够的安全边际。若H股跌至HK$7-8区间（对应公司总市值¥1,000亿以下），将进入「可买入」观察区。

## 八、投资结论

| 项目 | 结论 |
|:-----|:-----|
| **投资建议** | **观察** |
| 生意质量 | 中等（B） |
| 估值水平 | 合理偏低（H股）/ 合理（A股） |
| 管理层 | **优秀（A-）** |
| 综合评级 | **C+** |

### 买入策略
- **理想买入价**：公司总价值¥600亿以下 → H股约 **HK$7.0**
- **可接受买入价**：公司总价值¥850亿以下 → H股约 **HK$9.5**
- **当前H股股价**：HK$10.41（略高于可接受价）
- **建议仓位上限**：C+级 → **3-5%**
- **触发买入的信号**：
  1. 2026年Q2/Q3净利润环比企稳回升；
  2. 坦克/皮卡销量持续高增长，抵消哈弗下滑；
  3. 销售费用率见顶回落；
  4. H股股价跌破HK$9。

### 卖出触发条件
- 估值：公司总市值 > 内在价值 × 1.5（约¥1,300亿）→ 考虑卖出H股
- 基本面：坦克市占率被方程豹等大幅侵蚀 / 出口连续2季度下滑 / 毛利率跌破15% → 清仓
- 管理层：魏建军退休且无明确接班人 / 大额关联交易 → 重新评估

### 一句话投资论文

> 以**不足的安全边际**观察一家**细分领域有护城河但周期下行的民营车企**，市场因**新能源转型滞后**给予了H股8倍PE的折价，管理层**优秀且分红慷慨**，10年后最坏情况是**沦为二三线车企利润腰斩**，这需要**更低的买入价**才能接受。

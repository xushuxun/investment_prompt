## 二、生意分析

**核心问题：这家公司怎么赚钱？将来还能不能赚钱？**

### 商业模式

全球最大的新能源汽车垂直整合帝国：

- **新能源汽车**：2025年销量460.2万辆（+7.7%），蝉联全球新能源销量冠军；2026H1销量181万辆，海外出口79.2万辆（+67.8%）。
- **品牌矩阵**：王朝/海洋（大众市场，走量）、方程豹（个性化越野）、腾势（豪华）、仰望（超豪华）。
- **第二曲线**：动力电池（刀片电池外供）、储能系统（2026H1出货量全球第一）、比亚迪电子（智能终端+AI算力基础设施）、轨道交通（云轨/云巴）。
- **技术标签**：刀片电池、DM-i/DM-p混动、第二代刀片电池+闪充技术（2026年发布，5分钟充好/9分钟充饱）、天神之眼智驾、璇玑A3智驾芯片。

2025年营收8,039.65亿元（+3.46%），境外收入3,107亿元（+40%），占比升至38.6%。

### 护城河

| 类型 | 是否具备 | 强度 | 趋势 |
|:-----|:--------:|:----:|:----:|
| 品牌效应 | 有（全球新能源领导者心智） | 强 | 增强 |
| 转换成本 | 弱 | 弱 | — |
| 网络效应 | 无 | — | — |
| 规模经济 | **有**（460万辆年销、全产业链自研自产、单车成本行业最低之一） | 强 | **增强** |
| 成本/技术壁垒 | **有**（刀片电池、DM-i、闪充、垂直整合、研发人员超12万） | 强 | 增强 |

**护城河评级：宽** — 比亚迪是中国乃至全球新能源车企中唯一同时拥有规模、垂直整合、电池技术、混动技术、品牌矩阵和全球化产能的公司。这是八家公司中护城河最宽的。

## 三、管理层评估

**核心原则：宁要诚信普通的，不要能力强但不诚信的**

| 检验项 | 结论 | 说明 |
|:-------|:----:|:-----|
| 是否有造假/欺诈历史 | 无 | 未发现财务造假记录 |
| 股东诉讼 | 未发现重大 | — |
| 关联交易 | 有（弗迪系、比亚迪电子） | 垂直整合模式下大量关联交易，年报披露按公允定价，属行业特性 |
| 控股比例 | 王传福约16.9%；一致行动人（王传福+吕向阳+融捷+夏佐全）合计约33% | 控制权稳固，与股东利益一致 |
| 分红/回购历史 | 分红率低 | 2025年度10派3.58元，现金分红约32.6亿，分红率仅10%；股息率0.45%；未见大规模回购 |
| 资本运作 | 2025年高送转 | 每10股送8股+转增12股，总股本从30.39亿增至91.17亿股；摊薄每股指标但未稀释股权 |

**管理层评价：良好** — 王传福是技术型企业家，带领比亚迪穿越多个周期；一致行动人合计持股约33%，控制权稳定。扣分项：分红率偏低（利润大量投入研发与产能），2025年高送转虽合规但让每股价格「显得便宜」。

## 四、为什么便宜？（市场误判分析）

**PE 26x、PB 3.3x——比亚迪在价值投资者眼里并不便宜。**

| 市场担心的 | 实际情况 | 是否成立 |
|:-----------|:---------|:--------:|
| 价格战持续侵蚀利润 | 2025年净利润-19%，2026H1 -20.5%，毛利率从21%降至约18% | **成立** |
| 海外关税/政治风险 | 欧盟、美国、巴西、土耳其等已对中国电动车加征关税；比亚迪通过海外建厂（匈牙利、巴西、泰国）应对，但风险真实存在 | **成立** |
| 增速放缓 | 2025年销量+7.7%（此前数年翻倍式增长），2026H1销量仍有压力 | **成立** |
| 伯克希尔持续减持 | 巴菲特从20%高位减至约1.79%，是长期看空中国/新能源的信号 | **部分成立**（减持原因多元，不一定是看空基本面） |
| 垂直整合模式资本开支大 | 2025年资本开支约430-450亿，2026年仍需海外建厂；自由现金流较2023-2024年明显回落 | **部分成立** |

**我的信息优势/独特视角**：无。比亚迪是全球新能源龙头，所有信息都是明牌。市场给26x PE是在为「全球第一」的护城河和海外增长付费，这不是误判，是合理溢价。

## 六、内在价值估算

### 资产法（下行保护）

```
净现金：                                   ≈ 0（现金基本被有息负债匹配）
+ 应收账款 484 × 80%：                      +387
+ 存货 1,600 × 60%：                        +960
+ 固定资产+在建 3,393 × 40%：               +1,357
− 经营性负债（总负债6,400 − 有息1,319）：   −5,081
= 清算价值：                                ≈ −2,277亿（为负）
```

清算价值为负——汽车业的供应链占款模式决定资产法不构成保护。比亚迪的下行保护来自持续经营现金流和全球龙头地位，而非可变现资产。

### 盈利法（持续经营）

```
近5年归母均值（2021-2025）：(30.5+166.2+300.4+402.5+326.2)/5 = 245.2亿
× 10-12x = 2,452-2,942亿 ≈ 26.9-32.3港元/股
（此口径受早期低基数影响，偏保守）

情景估值（按2026E盈利）：
- 中性：2026E归母约450亿 × 12x = 5,400亿 ≈ 58.9港元/股
- 乐观：2026E归母约500亿 × 15x = 7,500亿 ≈ 81.8港元/股
```

### 综合内在价值：**每股约 55-75 港元，中枢 ≈ 65 港元**

**安全边际 = (65 − 91.95) / 65 ≈ -41%** — 当前价显著高于内在价值中枢，没有安全边际。

## 七、能力圈判定

- **10年后最坏情况**：全球新能源渗透率见顶，价格战持续，比亚迪利润率长期被压制在3-5%；海外因地缘政治扩张受阻；公司从「高增长龙头」变为「低增长制造业巨头」，估值中枢回落至15x PE以下，股价较当前有20-30%下行空间。但由于龙头地位和现金流，归零风险极低。信心度：中
- **最强的反对理由**：比亚迪是全球新能源车的「丰田+松下」合体，规模、成本、技术、品牌、全球化五维领先；当前26x PE对一家仍在海外翻倍增长的公司并不贵，长期看是合理买入价。
- **我的回应**：反对理由可能是对的，但李录框架不为「合理价」付费，只为「显著低于内在价值」的价格付费。比亚迪是好公司，但好公司需要好价格。当前价没有安全边际。
- **能力圈结论：明确在内** — 商业模式、财务、管理层均可理解；主要风险是可定价的行业竞争与地缘，而非不可知。

## 八、投资结论

| 项目 | 结论 |
|:-----|:-----|
| **投资建议** | **观察** |
| 生意质量 | 优秀 |
| 估值水平 | 合理偏高（无安全边际） |
| 管理层 | 良好 |
| 综合评级 | **B**（生意A，价格拖累） |

### 买入策略
- **理想买入价**：内在价值中枢 × 50% ≈ **32-33 港元**
- **可接受买入价**：内在价值中枢 × 70% ≈ **45-46 港元**（接近52周低点71.40仍有距离）
- **建议仓位上限**：A级 15-20% ｜ B级 8-10% ｜ C级 ≤3%
- **本标的建议仓位**：当前不建仓。触发条件：① H股跌至55港元以下且基本面未恶化；② 2026全年净利润预期上调至500亿以上且PE回落至20x以下。

### 卖出触发条件
- 估值：股价 > 内在价值 × 1.5（≈98港元以上，且盈利未同步上修）→ 减仓
- 基本面：季度毛利率跌破15%、海外销量连续两个季度下滑、核心市场份额被吉利/小米/问界显著蚕食 → 清仓
- 信号：市场按「全球第一车企」给予30x以上PE且媒体热度极高时——参考添柏岚卖出逻辑

### 一句话投资论文
> 比亚迪是全球新能源汽车领域护城河最宽的公司，ROE 15-19%、海外出口+67%、垂直整合无人能及——但PE 26x、PB 3.3x的价格没有给价值投资者留下安全边际；按李录纪律观察，等45-55港元以下的恐慌或盈利上修后的估值回落。

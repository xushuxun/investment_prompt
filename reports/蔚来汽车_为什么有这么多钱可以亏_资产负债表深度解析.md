**整理日期**：2026-06-03

> 本文回答一个核心问题：蔚来累计亏损超1,000亿，为什么还没有破产？钱从哪里来？资产负债表的"秘密"是什么？

## 一、答案速览：蔚来的"三大输血通道"

蔚来能持续亏损8年不倒闭，靠的是三条并行运作的输血通道：

```
┌─────────────────────────────────────────────────────────────┐
│              蔚来汽车 亏损资金来源结构                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  通道一：股权融资（最大来源）                                │
│  ├─ IPO前一级市场：    约150亿人民币                         │
│  ├─ 美股/港股7次增发： 约758亿人民币                         │
│  ├─ 合肥政府战略投资：  70亿人民币                           │
│  └─ 阿布扎比CYVN：     约170亿人民币                         │
│     小计：约1,148亿人民币                                     │
│                                                             │
│  通道二：债权融资（可转债为主）                              │
│  ├─ 6次可转债发行：    约239亿人民币                         │
│  └─ 银行借款/债券：    约200-300亿人民币                      │
│     小计：约500亿人民币                                       │
│                                                             │
│  通道三：供应商赊账（无息负债）                              │
│  ├─ 2024年末应付账款： 343.87亿人民币                        │
│  ├─ 2025年中应付账款： 逼近350亿人民币                        │
│  └─ 平均账期：         197天（近7个月）                       │
│     小计：约350亿人民币（无息、无成本）                        │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  累计外部输血：约2,000亿人民币                               │
│  累计亏损：     约1,090亿人民币                              │
│  差额去向：     资产沉淀（换电站/工厂/库存/无形资产）         │
└─────────────────────────────────────────────────────────────┘
```

**一句话总结**：蔚来不是"自己有钱"，而是"太会借钱"——股权融资超千亿、可转债数百亿、供应商无息赊账350亿。这些钱被用来填补每年的经营亏损，同时沉淀为换电站、工厂、研发等资产。

## 五、财务结构的"危险信号"

### 5.1 信号一：流动比率跌破1.0

```
流动比率 = 流动资产 / 流动负债

2021: 2.18  ✅ 健康
2022: 1.29  ⚠️ 下降

流动比率<1意味着：流动资产 < 流动负债
                    现有资产无法覆盖一年内到期的债务

## 六、蔚来"不会破产"的三个真相

### 真相一：会计破产 ≠ 实际破产

```
会计层面：
  归母股东权益 = -3.66亿 → 已经"资不抵债"

实际层面：
  只要还能融到资 → 不会破产
  只要供应商还愿意赊账 → 不会停产
  只要债权人还愿意展期 → 不会违约
  
蔚来的生存逻辑：
  "我不是靠盈利能力活着，我是靠融资能力活着"
```

### 真相二：供应商是"被动的人质"

这就是为什么蔚来能赊账350亿、账期197天的底层逻辑
```

## 八、结论：蔚来的资产负债表说明了什么？

### 8.1 核心结论

> **蔚来是一家"用股东资本和债权人信任做实验"的公司。**
>
> 它的资产负债表不是"健康企业"的资产负债表，而是"持续融资型亏损企业"的资产负债表。
>
> 在这个表上：
> - 资产端膨胀的是**不可变现的沉没成本**（换电站、NIO House、研发资本化）
> - 负债端膨胀的是**对供应商的无息欠款**（350亿，197天账期）
> - 权益端被**持续亏损完全侵蚀**（归母权益转负）
>
> 蔚来能活到今天，靠的不是盈利能力，而是**李斌的融资能力**和**供应商的"人质心态"**。
